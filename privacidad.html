Política de privacidad

Última actualización: 29 de octubre de 2026.

Qué datos trata Nexora Fact

Nexora Fact guarda los datos de facturación (empresa, clientes, documentos, contabilidad) en un archivo dentro del ordenador del usuario. El desarrollador no recibe ni almacena esos datos.

Google Drive

Si el usuario conecta su cuenta de Google, Nexora Fact usa el permiso drive.file, que solo permite acceder a los archivos que crea el propio programa: la carpeta «Nexora Fact» con la copia de la base de datos y un pequeño archivo de bloqueo. No puede ver ni modificar ningún otro archivo del Drive del usuario.

  • Los archivos se envían directamente entre el ordenador del usuario y Google Drive; no pasan por servidores del desarrollador.
  • El permiso de acceso se guarda solo en el ordenador del usuario (archivo nube.json).
  • El usuario puede desconectarlo desde el programa (Archivo → Google Drive → Desconectar) o retirar el acceso en myaccount.google.com/permissions.

El uso y la transferencia de la información recibida de las API de Google se ajustan a la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado. Esos datos no se usan para publicidad, no se venden y no se comparten con terceros.

Otras conexiones

El programa se conecta a Internet para comprobar la licencia y las actualizaciones, y para enviar los registros de facturación a la Agencia Tributaria (Veri*factu) cuando el usuario lo tiene activado.
